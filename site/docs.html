Installing and updates

Installing

BinderSetup.exe installs Binder for your account only, without an administrator prompt:

  • the app's files go to %LOCALAPPDATA%\Programs\Binder\;
  • it adds Binder to the Start menu, and to Settings › Apps › Installed apps through the value HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Uninstall\Binder.

That's all. The setup downloads nothing and installs no other software: the app carries its own runtimes. It reads every file back after writing it, and an update or uninstall only ever deletes the files it wrote. Your games, play history and settings are kept apart from the app, in %APPDATA%\Binder\, so updating or reinstalling leaves them as they are.

Start with Windows

When Start with Windows is on, Binder adds a value named Binder to HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run, the standard per-user startup list (also shown in Task Manager › Startup apps). It starts Binder with --background, so it waits in the notification area instead of opening. Turning the setting off removes the value.

Updates

  • Binder checks GitHub for a new version once a day, when it opens. Settings › About › Updates offers Install automatically, Ask before installing and Don't check; with Don't check, Binder makes no request at all.
  • The check downloads a list signed by Binder's author. Binder installs only a newer version whose signature, size and checksum match, and never an older one.
  • Before a version is signed, its setup is scanned with VirusTotal. It isn't released if one of the major antivirus engines (including Microsoft Defender's) or 3 or more engines flag it, unless the author overrides that with a reason, which then appears in that version's release notes.
  • It never installs while a game is running or Game mode still has changes applied. With Ask before installing, security fixes still install when you close Binder.
  • Downloads are kept in %LOCALAPPDATA%\Binder\updates\ and deleted once installed.
  • A copy built from the source code checks only if its build names a repository and signing keys. Without them it never checks, and Settings › About says This build doesn't check for updates.

Uninstalling

Uninstall Binder from Settings › Apps. It first puts back anything Game mode still has applied and removes the admin helper. It also removes Binder's Start menu entry and its Binder games folder. Then it asks whether to put your imported shortcuts back on the desktop, and whether to also delete your game list, play history and settings.

While you play

While a game runs

When you press Play, Binder shows Starting with the game's name, a countdown (10 seconds unless you set another for the game) and Keep open. It starts a small helper, Binder.Watcher.exe, which waits for the game to close. When the countdown ends, Binder itself closes, unless you chose Keep open. While you play, only the watcher is left:

  • Finding the game: every 2 seconds, for up to 3 minutes, it looks for a program running from the game's install folder, or for the one set under Process to watch in the game's details. If none starts, it opens Binder with Couldn't detect the game.
  • Once it's found: the watcher just waits for the game to close, without checking anything in the meantime. It uses under 3 MB of memory and no processor time.
  • When the game closes: it waits about 3 seconds for games that restart themselves, then adds the session as one line to %APPDATA%\Binder\sessions-<year>.jsonl. Time the PC was asleep isn't counted. Then it opens Binder again if Come back when the game closes is on.
  • After a crash: with Restart if it crashes on for the game, a game that crashed after playing for at least a minute is started again after 5 seconds, at most twice in a row.
  • Shutting down or signing out: the session is saved at once and nothing is reopened.

Binder only stays open if a game can't be followed (it has no install folder and no Process to watch); a notice then points to that setting. Because Binder isn't running while you play, its keyboard shortcut doesn't open it until the game closes; held, it can end a game that stopped responding (see Ending a stuck game).

Game shortcuts

Game shortcuts (on by default, in Settings › Opening Binder) play a game with Binder's keyboard shortcut and a number: with the default shortcut, hold Win+Shift, press G, then press a number. 0 is always the last game played; 1 to 9 are the games you give them. Windows uses Win+Shift and a number for the taskbar, so Binder can't register those keys. Instead, right after the shortcut and only while its keys are still held, Binder watches the keyboard for a number until they are let go (at most 15 seconds), and for Esc while the game's logo shows (about 1.5 seconds). Held for over a second, the keys show which game each number plays. It takes only the number or Esc it acts on and lets every other key through; nothing is recorded or stored. Letting go without a number opens Binder as before. At no other time does Binder watch the keyboard, and while a game runs Binder isn't running at all.

Ending a stuck game

End a stuck game (in Settings › When a game starts; When it stops responding by default, or Always, or Off) ends a game that froze in full screen, where Task Manager can't get in front of it. While the game runs, Binder's game watcher registers Binder's keyboard shortcut with Windows (no keyboard hook). Hold the shortcut: after 0.3 seconds a ring with an X appears in the middle of the screen, and its four parts fill one after another over 2.5 seconds; when all four are full, the game ends. A quiet hum goes with it, a voice added with each part, so the hold is heard where the ring can't be seen. Let go earlier and nothing happens; a short press shows nothing at all. Only while the keys are held does the watcher check, every 30 milliseconds, that they still are (the shortcut's keys, or the keyboard's repeat of the shortcut); it reads nothing else and stores nothing. With When it stops responding, a game is ended only while Windows reports its window as not responding, or while Windows Error Reporting (WerFault.exe) is still holding a game that crashed. This is checked when the ring would appear and again when it's full; a game that responds shows "is responding · nothing was ended" above the taskbar instead. What ends: the game's own processes that the watcher follows (inside its install folder, or its Process to watch), checked by their process id and start time, and a WerFault.exe from System32 that holds one of them. Never an anti-cheat service, a launcher or anything else. The ring shows over the game; a game is never minimized for it. Afterwards the session is saved as ended by you, Game mode is put back, and, if Come back when the game closes is on, Binder opens with a card: "crashed" or "stopped responding" only when Windows said so, otherwise "You ended [game]", with Play again. Restart if it crashes never restarts a game you ended. If Binder itself is open while the game runs (Keep open), the shortcut opens Binder as usual instead.

Game mode

Game mode changes a few Windows settings while a game runs and puts each one back when the game closes. It's off until you turn on Optimize Windows while I play in Settings › Game mode. You choose which of the items below it uses, and you can turn Game mode on or off for one game in that game's details.

How it works

  • When you press Play, Binder's small helper program (the one that waits for the game to close) applies the items you chose while the game starts. The game's priority and its network marking follow as soon as the game is found.
  • Before each change, the helper writes down what it's about to change and what it was before, in %LOCALAPPDATA%\Binder\gamemode-journal.json, and saves that to disk first.
  • When the game closes, and after about 3 seconds for games that restart themselves, everything is put back in reverse order. Only what is still the way Game mode set it is changed back: if you changed something yourself in the meantime, your setting stays.
  • If the game is never found, everything is put back straight away.
  • Settings that are already the way Game mode would set them are left alone and aren't counted as changes.
  • If the PC crashes or loses power during a game, the journal is still there. Binder puts it back the next time it starts, and the admin part when you sign in. Restore now on the Game mode page does it by hand.
  • Each step is written to %LOCALAPPDATA%\Binder\gamemode.log (View log on the Game mode page). The admin helper writes its own log to %ProgramData%\Binder\elevated.log.

The admin helper

Pausing services and the network items need administrator rights; everything else works without them. Allow… on the Game mode page, or All items on the last step of Binder's first-run setup, asks once, with the usual Windows prompt, and then:

  • copies a small helper, Binder.Elevated.exe, to %ProgramFiles%\Binder\, a folder only administrators can change;
  • creates two scheduled tasks for your account, Binder Apply and Binder Restore (followed by your account's ID). They run that helper with administrator rights, only while you're signed in. You can start them, but changing them needs administrator rights;
  • creates %ProgramData%\Binder\ for the helper's journal and log, which only administrators can change.

Windows asks again only if a Binder update changes the helper (Update… on the Game mode page), and when you remove the helper or uninstall Binder. Allowing it needs an administrator account; on a standard account, the items that need it can't be turned on and the others still work.

The helper does only what's listed on this page. It reads Binder's request from your user folder and checks everything in it again: only the four services below, only program file names (never Windows' own programs or security software), and only the upload limits Binder offers. Remove it on the Game mode page, or uninstalling Binder, puts back anything still applied and then removes the tasks, the folder and the helper.

Performance

Best performance power mode

On by defaultNo admin rights needed

What it does
On the Balanced power plan, the usual one on Windows 10 and 11, it sets the power mode to Best performance: the same as Settings › System › Power & battery › Power mode. If the power mode can't be set, or another plan is active, it switches to the High performance power plan instead.
Effect
The processor keeps higher clock speeds and reacts faster to load. Laptops use more power and can get louder.
Left alone
When Best performance, High performance or Ultimate performance is already on.
Put back
The exact power mode or plan from before, if it's still the one Game mode set.

Give the game priority

On by defaultNo admin rights needed

What it does
Once the game is found, its processes run at Above normal priority, the same as choosing it in Task Manager. Never High or Realtime, which can make the rest of Windows stop responding.
Effect
When other programs want the processor at the same time, Windows lets the game go first.
Left alone
A game that set its own priority keeps it. Some games and anti-cheat programs don't allow the change; the log says so.
Put back
Nothing to put back: the priority ends with the game's processes.

Background services

For each service below: Game mode only stops it, and never changes whether it starts with Windows. It's stopped only if it's running, accepts a stop and no other running service depends on it. After the game, it's started again only if Game mode stopped it and it hasn't been turned off meanwhile.

Pause Windows Search

On by defaultNeeds the admin helper

Service
Windows Search (WSearch)
What it does
The service keeps the search index for Start and File Explorer up to date by reading new and changed files. Paused, it doesn't read from the disk while you play.
While it's paused
Searching still works, but can be slower and may miss files changed during the game.

Pause SysMain

On by defaultNeeds the admin helper

Service
SysMain (SysMain), formerly Superfetch
What it does
The service loads programs you use often into memory ahead of time, so they start faster. Paused, it doesn't read ahead from the disk while you play.
While it's paused
Other programs may start a little slower until it runs again.

Pause Telemetry

On by defaultNeeds the admin helper

Service
Connected User Experiences and Telemetry (DiagTrack)
What it does
The service collects diagnostic data and sends it to Microsoft. Paused, it does neither while you play.
While it's paused
Nothing you'd notice. It isn't turned off: it runs again after the game.

Pause Print Spooler

Off by defaultNeeds the admin helper

Service
Print Spooler (Spooler)
What it does
The service handles printing. Paused, it stops checking printers and print jobs while you play.
While it's paused
You can't print until the game closes.

Pause Game Bar background recording

Off by defaultNo admin rights needed

What it does
Turns off Record what happened (Settings › Gaming › Captures) while you play, by setting HistoricalCaptureEnabled to 0 in HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\GameDVR.
Effect
Windows stops recording the last minutes of play in the background, which uses the graphics card's video encoder and the disk.
Left alone
When background recording is already off.
Put back
Turned on again, if it's still off.

Pause OneDrive syncing

Off by defaultNo admin rights needed

What it does
Closes OneDrive with its own /shutdown command, the same as Quit OneDrive in its menu, and waits up to 10 seconds for it to close.
Effect
No syncing while you play: no uploads, downloads or disk work from OneDrive. Files changed meanwhile sync after the game.
Left alone
When OneDrive isn't running, or when your Documents folder is inside OneDrive: games often keep their saves there, and files that are only online can't be opened while OneDrive is closed.
Put back
Started again with /background, if Game mode closed it and it isn't running already.

Network

The network items use Windows' policy-based Quality of Service, the same as the New-NetQosPolicy command. The policies go into a temporary store that Windows empties when it restarts, so none can stay behind for long. Each is named starting with "Binder", and Game mode only ever removes policies with that name.

Game and voice chat first

On by defaultNeeds the admin helper

What it does
Marks the network traffic of the game and of voice chat apps as urgent (DSCP 46, "expedited forwarding").
Which apps
The game's own programs, once it's found; Discord, TeamSpeak, Mumble, Teams and Zoom when they're installed; and the apps you add under Apps kept smooth.
Effect
A router that honours the marking sends this traffic first when the connection is busy. Many home routers ignore it; then nothing changes.
Put back
The policies are removed.

Slow down background uploads

On by defaultNeeds the admin helper

What it does
Limits how fast each app on the list can upload: 1, 5 or 20 Mbit/s, chosen under Upload limit. The default is 5 Mbit/s.
Which apps
OneDrive (OneDrive.exe), Google Drive (GoogleDriveFS.exe) and Dropbox (Dropbox.exe), and the apps you add. Never a Windows service, Windows' own programs, security software listed in Windows Security, or another account's programs.
Effect
A large upload can fill the connection and cause lag. This limits only what the apps send; downloads can't be limited on the PC itself. Steam pauses its downloads while you play; Epic and Battle.net have a download limit in their own settings.
Put back
The policies are removed.

Limit Windows Update downloads

On by defaultNeeds the admin helper

What it does
Limits Windows Update's background downloads (Delivery Optimization) to 10% of the bandwidth, by setting the policy DOPercentageMaxBackgroundBandwidth in HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows\DeliveryOptimization.
Left alone
When a limit of 10% or less is already set.
Put back
Exactly the value from before, including "not set", and the policy key is deleted again if Game mode created it. Only if the value is still the one Game mode set.

Apps while playing

You can add apps that have a window and choose for each one:

Close
Binder asks the app to close the way its close button would, and waits about 5 seconds. An app that's still open then (it asked to save something, has no window or runs as administrator) is left open and isn't reopened. Apps that closed are started again after the game, from the same program file, without extra options.
Calm
The app runs in efficiency mode (the green leaf in Task Manager) until the game closes: Windows runs it at its most efficient speed, and on processors with efficient cores mostly on those. Unlike Task Manager, Binder doesn't lower its priority. Afterwards only that same process is changed back, if it's still in efficiency mode.

Programs are never ended. The game's own files, Windows' programs, Store apps and Binder itself can't be closed or calmed.

Windows' own settings

The Game mode page also shows three of Windows' own settings, with buttons that open them in Windows Settings. Binder only reads them and never changes them.

Game Mode
Windows' own game mode (Settings › Gaming › Game Mode). While a game runs, Windows gives it priority and holds back driver installs and restart prompts from Windows Update.
Optimizations for windowed games
Settings › System › Display › Graphics. Lowers latency for games in a window or borderless window. Not shown on Windows 10.
Do not disturb
Windows can turn it on during full-screen games: When playing a game under Turn on do not disturb automatically, in Settings › System › Notifications.

What Game mode never does

  • End a program, or close one that has unsaved work.
  • Change whether a service starts with Windows, or touch any service other than the four above.
  • Touch Microsoft Defender, Windows Update's own services, Xbox and gaming services, anti-cheat, audio, networking, the desktop or File Explorer.
  • Change settings that need a restart or lower security, such as hardware-accelerated GPU scheduling or virtualization-based security.
  • Use tricks that don't measurably help or can harm, such as clearing standby memory, timer resolution or core parking changes.
  • Set any program to High or Realtime priority, or lower another program's priority.

Your games and data

Desktop shortcuts

Import desktop shortcuts lists the shortcuts on your desktop and the shared (Public) desktop; you tick which are games. Those are moved, not deleted, to %APPDATA%\Binder\Shortcuts\. A shortcut on the shared desktop that needs administrator rights to move is copied instead, and the original stays. Shortcuts are only read while they're listed, never run. Restore in Settings › Desktop shortcuts moves them back onto your desktop. Right after an import, Undo in its notice moves that import's shortcuts back.

Your games in Start search

Add my games to Start search (off by default; in Settings and on the first page of Binder's first-run setup) gives each game that Start search doesn't find yet a shortcut in its own folder, %APPDATA%\Microsoft\Windows\Start Menu\Programs\Binder games\. Each shortcut runs Binder.exe --play with the game's id, so a game started from Start is played the same way as from Binder; an id that isn't a game in your list just opens Binder. Games that already have their own Start entry, such as a Steam shortcut, get none, and existing Start entries are never changed. To tell which games Start finds, Binder reads the shortcuts in your and the shared Start menu, without running them. The folder follows your game list: when Binder looks for new games, and when you import, add, hide or remove one. Turning the setting off, or uninstalling Binder, deletes the shortcuts in that folder and then the folder.

Free up space

Free up space suggests games you could remove to make room on a drive. Binder never deletes game files itself: each uninstall is handed to the game's own launcher, which asks before it removes anything.

Your data

  • %APPDATA%\Binder\: your game list, settings, playtime and imported shortcuts.
  • %LOCALAPPDATA%\Binder\: cover pictures, logs, Game mode's journal while a game runs, and downloaded updates.
  • %ProgramData%\Binder\: only if you allowed Game mode's admin helper; its journal and log.

Binder sends nothing about you or your PC anywhere. Besides the update check, it only downloads cover art for Steam games that Steam hasn't stored on your PC, once each, from Steam's servers, or from the HTTPS address you set in Settings › Advanced instead (that page names its server). Downloads are only ever opened as pictures.
