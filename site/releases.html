Binder 0.2.0

15 November 2026

  • Binder can now update itself: Settings › About shows new versions and what's new.
  • Choose in Settings › About whether updates install automatically, after asking, or not at all.
  • An update replaces all files together, or none if something goes wrong.

Going back to an earlier version: run its setup. It installs over the current one and says when a newer version is installed. Your game list and settings aren't touched.

Binder checks for updates once a day and would bring the newest version back. To stay on an earlier one, choose Don't check under Settings › About › Updates.

To check a download, compare its SHA-256 with the one listed here; in PowerShell: Get-FileHash .\BinderSetup-*.exe. Each release's VirusTotal scan is on its GitHub page, and every release is listed on GitHub.
